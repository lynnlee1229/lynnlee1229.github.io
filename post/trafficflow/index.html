Traffic Flow Prediction: A Research Resource Directory

An archived collection of papers, competition solutions, PyTorch examples, and spatiotemporal forecasting resources from my earlier research.

Lynn LeePublished 2020-08-223 min read
Read in Chinese →

An archived study note, kept with its original date. This English reading edition clarifies version-sensitive statements; the original Chinese is available via the language switch.

I assembled this directory while studying traffic-flow prediction. My focus later moved to data engineering, and I stopped maintaining this collection. The original repository remains available for anyone interested in continuing the work: Traffic Flow Prediction Resources repository .

This is an archive of the resources collected at the time, not a current ranking of frameworks or a claim that every external page is still maintained. It includes official documentation, research resources, community tutorials, and competition submissions; those serve different purposes. The language is noted where the linked material is primarily in Chinese.

The directory follows the original progression: general learning resources, example projects, project structure and data preparation, model families, implementations, and algorithm references. Repeated descriptions have been shortened while preserving every original resource link.
