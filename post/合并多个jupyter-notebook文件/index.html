Merging Jupyter Notebooks and Fixing an Encoding Problem

An archived note on combining notebook cells and outputs with nbmerge, and diagnosing an incorrectly encoded output file.

Lynn LeePublished 2021-10-212 min read
Read in Chinese →

An archived study note, kept with its original date. This English reading edition clarifies version-sensitive statements; the original Chinese is available via the language switch.

Why I needed to merge two notebooks

While using Jupyter for study notes, I wanted to combine my own notebook with another notebook that already contained the results of a long training run. Re-running the training just to place the results alongside my notes would have been expensive, so I looked for a way to merge the files themselves.

Using nbmerge

The nbmerge utility provides a simple command-line interface:

pip install nbmerge

For two input files named 1.ipynb and 2.ipynb, the original command was:

nbmerge 1.ipynb 2.ipynb > 3.ipynb

Run it from the directory containing the input notebooks. The cells and stored outputs are combined in order. This operation merges notebook documents; it does not reconcile variable names, execution order, dependencies, or model state. The result still needs a review before anyone treats it as a reproducible computation.

The output was unexpectedly large

In my original Windows workflow, the merged file was much larger than the two inputs combined, and Jupyter could not open it. Inspecting the error and opening the file in a text editor pointed to an encoding problem.

Saving the merged JSON document as UTF-8 resolved the issue in that case. The resulting size became roughly comparable to the combined inputs, and Jupyter could read the notebook again.

This was an observation about that shell and encoding setup, not a claim that every merge problem has the same cause. Notebook outputs can also contain large embedded images or other binary data encoded as text.

A more explicit output path

The utility also supports writing to an output file directly:

nbmerge 1.ipynb 2.ipynb -o 3.ipynb

Using the tool’s file-output option avoids depending on the shell’s redirection encoding. After merging, check that the output is valid notebook JSON, that its cells appear in the intended order, and that the stored outputs are attributed to the correct code. Keep the original inputs until the combined notebook has been verified.

The lesson from this small debugging session was straightforward: an .ipynb file is a structured text document. When a file suddenly grows and becomes unreadable, inspect the encoding and serialization before assuming the notebook content is broken.
