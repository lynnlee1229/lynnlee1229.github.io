Evidence files and method
Task counters are extracted from Spark TaskEnd events. Failed attempts are retained. Shuffle read bytes include local and remote reads; all remote reads in this local baseline are zero. Shuffle write records can represent batched serialized objects, especially in PySpark. Peak execution memory is a maximum per task, not process RSS.
