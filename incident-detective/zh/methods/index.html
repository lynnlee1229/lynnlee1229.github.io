故障侦探馆是一款练习不完整运维证据推理的浏览器游戏。六个一致的编写案件取材于公开合成实验，不含公司内部事故或真实玩家遥测。

调查循环

  1. 阅读目标，区分症状与机制。游戏没有倒计时。
  2. 花预算打开日志、指标、计划或配置，每份仅收费一次。预算不能退回，所有文件加探针的总费超过预算。
  3. 在工作板保留多个假设。标记只是你的笔记，不是自动诊断。
  4. 先预测因果关系，再解锁验证台。将一个变量的改变与基线比较，重复免费，首次预测锁定。
  5. 提交机制、处置与最多三份已获取引用。允许明确选择“证据不足”。提交后揭示可解释复盘与完整证据档案。
  6. 重置案件恢复预算，保留最高分。清除全部进度可删除存档。切换语言保留案件深链。

六种探针模型

  • Join：选择保存的公开策略，对比所有输出分区与精确总数/加权和，不虚构速度提升。
  • 线程池：t=0,2,…34 ms 共 18 次到达，双线程、固定 60 ms 服务、FIFO 队列、满时立即拒绝。省略 JVM 调度与 I/O 波动。
  • 期限：理想工作 240 ms，调用者 40 ms 超时。只有传递期限并协作退出才在 40 ms 结束，否则在 240 ms 结束。不执行远端副作用。
  • 计数对齐：错误与完成计数需有相同窗口和口径。无效的商不能解释为比率。
  • 锁：固定同顺序调度有 B → A；相反顺序形成环并回滚一个受害者。调用在事务内时持锁 8,020 ms，移至 BEGIN 前时 20 ms。这是模型，并非实际 SQL 执行。
  • 重试：持续失败、12 个逻辑请求，尝试上限含首次。次数 = min(12 × 外层 × 内层，总上限)，无上限视为无穷。抖动改变时序，不改次数。全局上限不模拟公平性。

隐私与可访问性

游戏不调用 API，不接收个人文本、日志或文件。进度保存默认关闭。开启后，仅在本站来源的 localStorage 保存预定义选项、已获取文件 ID、探针参数与分数。双语版本共享该可选存档。存档不加密，本浏览器配置的使用者可清除它。存储被禁用或损坏时，使用内存模式游玩。

所有控件支持 Tab 与 Enter/空格，选择框支持方向键。不要求拖拽、悬停、计时、音频或只靠颜色判断。提供跳到正文、可见焦点、减少动画与图表计数文本。

案例刻意具有可检查的固定解答。浏览器 JavaScript 可以查看；源码仓库私有并不使游戏答案保密。不向服务器发送玩家数据。
