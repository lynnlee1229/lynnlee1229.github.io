1. A point on the boundary

Load the synthetic sample. The polygon region-a has a hole; region-b overlaps it. In Geofence mode, click the coordinate plot or enter longitude and latitude. Try [114.3, 30.59] inside region-a, [114.3, 30.61] inside its hole, and [114.28, 30.60] on the exterior edge.

Toggle “Include boundary”. The reported geometric location stays “boundary”, while membership changes. A hole interior is outside; a hole edge is a boundary. Ring winding direction does not change this Lab’s point-location result.

2. Associate observations with regions

Switch to Spatial join. With boundaries included, the sample produces four point-polygon pairs from three matched points. The overlap point matches both regions. With boundaries excluded, the edge point no longer matches and three pairs remain.

Export the annotated GeoJSON. Every Point gets a lab_matches array containing all matches; original properties and other features are retained. The result table is capped at 500 visible pairs, while the export includes every computed match.

3. Measure a prefilter

Run the seeded benchmark below the workbench. It generates 1,500 points and 36 polygons with seed 42, then compares a full pair scan with a bounding-box prefilter. Both methods apply the same exact point-in-polygon test; the benchmark verifies identical match lists.

Each method warms up once and is measured five times in alternating order. The displayed time is the median and includes validation. Exact-test counts describe work avoided; elapsed times depend on browser, device, geometry and system load. A prefilter is not guaranteed to be faster for every input.

4. Inspect a trajectory spike

Switch to Trajectory. LineString features need properties.timestamps with one strictly increasing, timezone-qualified ISO timestamp per coordinate. The sample has one isolated jump at point index 2. At 120 km/h, both adjacent segments are fast but the bridge from point 1 to point 3 is plausible.

The review preview omits that isolated candidate. Amber shows the original; teal dashed shows the preview. Export the preview only after checking the flagged segments. A fast segment may be a real trip, a timestamp error or a coordinate error. This heuristic does not identify which explanation is true.

5. Bring your own data

Export a WGS84 GeoJSON FeatureCollection from your GIS workflow. Use explicit feature IDs so exported matches remain traceable. Import the file or paste its JSON, select the experiment, then choose Analyze input.

For trajectories, put one timezone-qualified timestamp per coordinate in properties.timestamps. Download the result after inspection; the tab does not retain files after closing. The entire workflow is available in this browser without installation, a map account or an API key.
