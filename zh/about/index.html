关于我

Lynn Lee，数据工程师。关注广告实时数据、分布式计算与 AI Agent 的工程落地。

你好，我是Lynn Lee。

目前在腾讯广告从事数据工程，工作围绕广告用户行为数据、实时计算与数据质量展开。我喜欢把复杂链路拆成可以观察、可以验证、可以恢复的部分，再逐步把它做稳。

这份博客是我的工程笔记：写清楚设计的前提，记录方案的边界，也留下验证结论的方法。

我在做什么

广告数据与实时计算

参与广告实时数据平台升级，推进历史 Java / Flink 任务向标准化链路迁移。围绕升级对账、行为关联、实时去重、任务巡检与计算资源优化，持续改善数据链路的正确性和可维护性。

海外数据基础设施

参与基于 AWS 的海外广告用户行为数据系统建设，处理异构媒体接入、流批处理与协议映射。关注 S3、Iceberg、MSK 等组件之间的数据契约，以及配置化接入和变更的验证过程。

AI Agent 工程

探索智能运维与 Data Agent：让告警分析、证据检索、问题定位和数据查询形成可追踪的工作流。使用过 LangChain、AWS Bedrock 等工具，也在实践 SDD、TDD 与 Skill 化的开发流程。

我的做事方式

  • 先定义“对”。 把输入、输出、数据口径与失败语义说清楚。
  • 用证据做判断。 对账、回放、压测、执行计划，比“感觉应该没问题”更可靠。
  • 让改动可恢复。 小步上线，保留追踪信息和回滚路径。
  • 把重复工作写进工具。 让脚本、流程和 Agent 承接可验证的重复劳动。
