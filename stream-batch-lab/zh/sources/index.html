03如何使用引用

上游文档解释组件支持的语义；本地 SQL 说明项目实际配置了什么；保存的运行记录说明特定环境中观察到了什么。要得出强结论，应同时使用这三类资料。

链接中的 ClickHouse 文档持续更新，请结合固定的服务端版本理解行为。资料在 2026-11-07 为本次发布核查，上游页面仍可能变化。即使某组件支持更多功能，本项目的已知局限依然适用。

04可继续研究的问题

  • 固定输入与字段级对账如何提高回归验证的价值？
  • 要让删除正确传播到查询服务层，需要哪些改动？
  • 持久化作业恢复、定期湖表维护和明确的时间语义，会怎样改变运行设计？
  • 如何在相同工作负载、正确性检查和资源限制下比较表格式？
