03How to read a citation

An upstream document explains a component’s supported semantics. The local SQL shows what this project actually configures. A saved run shows what was observed in a specific environment. Use all three when making a strong claim.

ClickHouse’s linked documentation is maintained continuously, so check behavior against the pinned server version. References were reviewed for this publication on 2026-11-07; upstream pages may change. The lab’s own limitations remain explicit even when a component supports additional features.
