对照验证了什么
无限制策略是反例：单靠虚拟线程不会执行声明的资源容量限制。等待与拒绝使用真实 Semaphore 许可。queued 是登记等待的数量，不是 JVM 内部队列采样。等待策略没有独立队列长度上限，本实验的突发请求是有限的。
等待中取消不得进入下游。协作持有者退出并归还许可。忽略中断的对照在 Future 取消后仍活跃，随后释放门闩并检查全部许可归还。“cancelled”统计观察到中断的任务生命周期，也包含这个有限对照。
JEP 491 在 JDK 24 消除了 synchronized 相关 pinning。下方 pinned 计数仅代表本负载的采集结果，不虚构事件，也不以缺失作证明。结构化并发仅作可选 preview 阅读，本实验未启用 preview。
